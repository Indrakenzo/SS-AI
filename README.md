# SS-AI
SS-AI adalah asisten Penetration Testing berbasis kecerdasan buatan (AI) yang dibangun untuk beroperasi secara ketat sesuai dengan Rules of Engagement (RoE).   Dikembangkan oleh Indrayaza Z, proyek ini dirancang sebagai panduan, alat edukasi, dan asisten audit keamanan (Ethical Hacking) yang memastikan pengguna berada di jalur legal.
